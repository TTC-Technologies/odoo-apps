# Odoo apps by T.T.C. SAS

Odoo modules published by T.T.C. SAS on the
[Odoo Apps Store](https://apps.odoo.com/apps/modules/browse?author=T.T.C.%20SAS).
One branch per Odoo version, one folder per module. This repository holds
released versions only.

| Module | Name | Odoo |
|---|---|---|
| [`expense_scan`](expense_scan) | Receipt Scanner for Expenses: an expense filled in from a photo of the receipt, read by an OCR that runs on your own server. | 19.0 |

## Installation

Copy the module folder into your addons path, install its dependencies (see
the README of the module), then install it from Apps.

## Development and issues

Each module is developed in its own repository, where issues, questions and
early-access versions are:

- `expense_scan`: https://github.com/Ch0c0latine/expense_scan
